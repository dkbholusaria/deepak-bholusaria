DocUnlok

Strip password protection from PDF files — in place, on your own machine.

Download for Windows Standalone .exe · no install, no account Release notes Changelog & older versions

What it does

Multi-file select

Pick any number of PDFs at once, from any folder or drive.

In-place decrypt

Removes owner + user password, same filename and folder.

Safe by design

Decrypts to a temp file, verifies it opens unencrypted, only then replaces the original.

Batch-friendly

Wrong password or already-unencrypted files are reported per file — the batch keeps going.

Responsive UI

Processing runs on a background thread, so the app never freezes.

No upload, ever

100% local. Your PDFs never leave your computer.

How to use

  1. Download and run DocUnlok.exe — no installation needed.
  2. Select Files… to choose one or more password-protected PDFs, or Add Files… to bring in more from other folders.
  3. Type the password shared by those PDFs.
  4. Remove Password — each file's status updates live in the table: decrypted, already unencrypted, or failed with a reason.
